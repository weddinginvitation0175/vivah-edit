How to Open in After Motion Z / Alight Motion

project.xml downloaded

1 Chrome [Open] Button (Fastest)

Open phone's Downloads folder in File Manager, tap the downloaded XML file (or tap Share), and pick After Motion Z.

Send the file to yourself on WhatsApp/Telegram. Tapping the file in chat directly imports it into After Motion Z!
